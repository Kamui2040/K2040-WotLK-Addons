# K2040 Loot & Salvage - AddOnSkins

This optional bridge gives K2040 Loot & Salvage an ElvUI/AddOnSkins look. It changes presentation only; the main addon keeps working without it.

## Requirements

- K2040 Loot & Salvage `0.1.0`
- ElvUI for WotLK 3.3.5a
- ElvUI AddOnSkins `1.06` or a compatible version

## Install

1. Install the three required addons first.
2. Extract `K2040_LootAndSalvage_AddOnSkins` into `World of Warcraft/Interface/AddOns`.
3. Enable **K2040 Loot & Salvage - AddOnSkins** on the character-selection AddOns screen.

The bridge is a separate addon. It does not replace or modify files inside ElvUI or AddOnSkins. Delete its folder to return to the normal K2040 Loot & Salvage appearance.

## Scope

The bridge skins the settings pages, checkboxes, dropdowns, edit boxes, sliders, lists, Quick Lists window, and manual profession window. AddOnSkins and ElvUI remain third-party requirements and are not included in this download.
