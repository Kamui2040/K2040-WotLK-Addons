# Contributing

Bug reports and focused pull requests are welcome.

Please describe:

- what happened and what you expected;
- the exact WotLK client build;
- which bag, UI, and profession addons were enabled;
- whether the problem also happens after `/reload`.

Do not attach real account files or unsanitized SavedVariables. Remove character, realm, guild, and server details from logs and screenshots.

Before opening a pull request, run the checks listed in [AGENTS.md](AGENTS.md). Keep changes compatible with Lua 5.1 and Interface `30300`, and do not add third-party code or artwork without clear redistribution rights.
